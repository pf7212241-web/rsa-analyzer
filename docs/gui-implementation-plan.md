# Реализация графической оболочки

Проект gui-design.md согласован пользователем 10.11.2026.

1. Добавить адаптер DLL для существующего ввода и отчёта; проверить ABI структур на границе C/Python. Математическое ядро не дублировать.
2. Реализовать Python-клиент библиотеки и изолированный рабочий процесс. Возвращать структурированные результаты и отчёт одного завершённого запуска.
3. Сделать вкладки анализа, настроек, инструкции; пример Ферма и Полларда, обработку ошибок, остановку, сохранение и маркировку устаревших результатов.
4. Проверить ядро, интеграцию, граничные значения, рабочий процесс и реальные экраны.
5. Упаковать Windows x64 приложение с Python/Tk и DLL, проверить переносимую поставку, обновить инструкции.
