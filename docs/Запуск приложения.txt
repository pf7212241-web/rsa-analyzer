RSA — оценка ключей
Курсовая работа. Автор: Филиппов Павел.

1. Распакуйте весь архив в любую доступную папку Windows x64.
2. Откройте RSA-Analyzer.exe. Python и компилятор устанавливать не нужно.
3. Откройте вкладку «Инструкция» и нажмите «Подставить пример Ферма».
4. На вкладке «Анализ» нажмите «Выполнить анализ».
5. Для n = 10403, e = 7 программа найдёт множители 101 и 103.
6. Кнопкой «Сохранить отчёт…» сохраните результаты под новым именем.

Не отделяйте exe от папки _internal: в ней находятся библиотека C,
Python, Tkinter и примеры. Передавать нужно всю папку приложения.

Программа работает локально, без подключения к интернету.
Вычислительный диапазон — до 64 бит. Для больших чисел доступна
проверка записи и разрядность. Отсутствие найденного разложения
не доказывает криптографическую стойкость ключа.

Файлы с ключами: UTF-8, одна запись n e либо n e p q d на строку.
Неизвестные p, q, d обозначаются дефисом. До 256 записей.
Примеры находятся в _internal/examples и доступны из инструкции.

Кнопка «Остановить» отменяет текущий расчёт; ранее завершённый
отчёт остаётся доступен. Изменение полей не меняет старый отчёт:
для получения новых результатов запустите анализ повторно.
